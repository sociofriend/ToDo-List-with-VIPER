# VIPER iOS App

This project is built using the **VIPER architecture** for iOS development.  
VIPER helps separate responsibilities clearly, making the app **scalable, testable, and maintainable**.

---

## VIPER Overview

VIPER stands for:

- **View** – Displays UI and captures user input.  
- **Interactor** – Contains business logic and communicates with data layers.  
- **Presenter** – Handles presentation logic and formats data for the View.  
- **Entity** – Models and represents pure data objects.  
- **Router (Wireframe)** – Handles navigation and module assembly.
